# Техническое задание: Говорящая Распределяющая шляпа

## 1. Общее описание проекта

Интерактивная копия Распределяющей шляпы (Sorting Hat) из вселенной "Гарри Поттер" на базе Raspberry Pi 5. Устройство должно:
- Двигать "ртом" и "бровями" (мимика) синхронно с речью
- Вести голосовой диалог с пользователем через ИИ
- "Видеть" человека через камеру перед началом диалога и учитывать его внешний вид в репликах
- Иметь характер и стиль речи, соответствующий персонажу

---

## 2. Аппаратная часть (Hardware)

### 2.1 Уже есть
- Raspberry Pi 5
- Паяльник, отвёртки
- Микрофон (миниджек)
- Bluetooth-колонка
- ELEGOO ESP-32 Super Starter Kit (используем частично: breadboard, dupont-провода, резисторы, 1× SG90)

### 2.2 Требуется докупить
| Компонент | Назначение | Статус |
|---|---|---|
| PCA9685 | Драйвер до 16 сервоприводов через I2C | заказано/в пути |
| SG90 сервоприводы (3-4 доп.) | Механизм рта, бровей | заказано/в пути |
| Блок питания 5V/3A (переделка из старого адаптера) | Питание сервоприводов отдельно от Pi | есть на руках |
| USB-звуковая карта с mic-in | Подключение аналогового микрофона к Pi 5 (нет 3.5мм входа) | заказано/в пути |
| Raspberry Pi Camera Module 3 (CSI) | Снимок человека перед диалогом для описания ИИ | нужно заказать |

### 2.3 Схема подключения (общая логика)
- Pi 5 → I2C (GPIO 2 SDA, GPIO 3 SCL) → PCA9685 (сигнальная часть, питание 3.3V от Pi)
- PCA9685 силовые клеммы V+/GND → отдельный блок питания 5V
- Сервоприводы → каналы 0-3 (или больше) на PCA9685
- Микрофон (миниджек) → USB-звуковая карта → Pi 5 (USB)
- Bluetooth-колонка → сопряжение по Bluetooth с Pi 5
- Камера (CSI-модуль) → камерный разъём Pi 5, объектив спрятан в ткани шляпы (например, зона "глаза" или брови)

### 2.4 Механика шапки
- Мягкая ткань шапки не держит форму — требуется внутренний каркас
- Сервоприводы крепятся на жёсткой платформе (пластик/оргстекло/3D-печать), зафиксированной внутри шапки в статичной зоне (затылок/макушка)
- От рычага сервопривода идёт тяга (леска или тонкая проволока) к гибкому проволочному каркасу (алюминий/сталь 1.5-2мм), вшитому в ткань по контуру рта и бровей
- Требуется предварительный макет на столе для отладки длины тяг и углов поворота до встраивания в шапку

## 3. Программная часть (Software)

### 3.1 Архитектура

```
[Камера на Pi] → [Снимок человека] → [Отправка по локальной сети на Mac (Ollama API)] 
                                                              ↓
                                    [Vision-модель на Mac M1 Pro: LLaVA/Qwen2.5-VL] → [Текстовое описание]
                                                              ↓
[Микрофон] → [Запись аудио] → [Распознавание речи (Whisper)] 
    → [Текст + описание внешности] → [Claude/GPT API + системный промпт персонажа] 
    → [Текст ответа] → [Синтез речи (TTS)] 
    → [Bluetooth-колонка] + [Синхронизация движения рта по амплитуде звука]
    → [PCA9685] → [Сервоприводы]
```

**Важно про приватность:** снимок с камеры никогда не покидает домашнюю сеть — обрабатывается локально на Mac (M1 Pro) через Ollama, в облако уходит только текстовое описание (без фото) в составе промпта для диалоговой ИИ.

### 3.2 Модули

**Модуль 1: Голосовой ввод**
- Захват аудио с микрофона (USB-звуковая карта)
- Определение начала/конца фразы (voice activity detection) либо запуск по кнопке/слову-триггеру
- Распознавание речи — Whisper (локально на Pi 5, модель tiny/base для скорости)

**Модуль 2: ИИ-диалог**
- Отправка распознанного текста в Claude API (или GPT API)
- Системный промпт задаёт личность Распределяющей шляпы (см. раздел 4)
- Получение текстового ответа

**Модуль 1.5: Зрение (локальное, приватное)**
- Перед началом диалога — один снимок камерой на Pi
- Снимок отправляется по локальной сети (WiFi/LAN) на домашний Mac (M1 Pro) — фото НЕ уходит в интернет
- На Mac через **Ollama** крутится локальная vision-модель (LLaVA или Qwen2.5-VL), которая генерирует текстовое описание человека
- Готовое текстовое описание (без самого фото) отправляется обратно на Pi и добавляется в промпт для Claude API
- Требование: Mac должен быть включён и в той же локальной сети, что и Pi, во время использования шапки

**Модуль 3: Синтез речи**
- Преобразование текста ответа в аудио (TTS)
- Варианты: локальный TTS (быстрее, ниже качество) или облачный (ElevenLabs/аналог — платно, выше качество и атмосфернее звучит)
- Воспроизведение через Bluetooth-колонку

**Модуль 4: Синхронизация движения**
- Анализ амплитуды/громкости синтезированного аудио в реальном времени
- Преобразование амплитуды в угол поворота сервопривода "рта" (чем громче — тем шире открыт рот)
- Опционально: случайные лёгкие движения "бровей" для оживления мимики во время речи

**Модуль 5: Управление сервоприводами**
- Библиотека для PCA9685 (adafruit-circuitpython-pca9685)
- Функции: открыть/закрыть рот, поднять/опустить брови, калибровка минимальных/максимальных углов
- Плавное движение (интерполяция между позициями, чтобы избежать резких рывков)

### 3.3 Технологический стек
- Python 3 (основной язык)
- Whisper (распознавание речи, локально)
- Anthropic API / OpenAI API (диалог)
- TTS: пока не выбран — определить на этапе тестирования (см. открытые вопросы)
- adafruit-circuitpython-pca9685 (управление сервоприводами)
- pyaudio / sounddevice (захват и анализ аудио)
- Ollama + LLaVA/Qwen2.5-VL (локальное описание внешности, запускается на Mac M1 Pro в домашней сети)

## 4. Личность и характер шапки

*(Раздел для доработки — черновой промпт)*

Распределяющая шляпа должна:
- Говорить загадочно, мудро, с лёгкой иронией — в стиле оригинального персонажа
- Обращаться к собеседнику официально, иногда с юмором
- При запросе "распредели меня" — задавать несколько вопросов о характере и выдавать один из 4 факультетов Хогвартса с обоснованием
- Избегать длинных ответов — реплики должны быть краткими, как в фильме/книге

*(Финальный текст системного промпта будет прописан отдельно)*
